# DishHomie

**Your Daily Dish Helper — Pick • Spin • Plan • Cook**

A Filipino dish picker, roulette and weekly lunch/dinner planner with recipes and grocery lists.

## Start

Open `index.html` after it is uploaded, or enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Data and privacy

Custom dishes, weekly picks, favorites and shopping checkmarks stay in your own browser storage, not synced across devices. Export JSON backup before clearing browser data.

No third-party source code license is granted by default; image assets require their own attribution. See `CREDITS.md`.
